プライバシーポリシー

ウラガワ投稿ツール(以下「本ツール」)/ 制定日:2026年10月11日

1. 本ツールについて

本ツールは、YouTubeチャンネル「ウラガワずんだもん」の運営者が、自分のチャンネルを管理するためだけに使う個人用ツールです。運営者以外の利用者はいません。

2. 利用するGoogleユーザーデータ

本ツールは、運営者本人が許可したGoogleアカウントについて、YouTube Data API を通じて次の操作だけを行います。

  • 運営者のチャンネルの動画一覧・動画情報の取得
  • 運営者のチャンネルの動画のタイトル・説明文・タグ・サムネイルの設定
  • 運営者のチャンネルへの動画のアップロード

3. データの保存・共有

認証に必要な情報(アクセス用の鍵)は、運営者が管理する作業環境にのみ保存します。取得した情報を第三者に販売・提供したり、広告に利用したりすることはありません。

4. YouTube・Googleの規約

本ツールは YouTube API Services を利用しています。YouTube利用規約およびGoogleプライバシーポリシーが適用されます。

5. 許可の取り消し

Googleアカウントの権限設定ページから、本ツールへのアクセス許可をいつでも取り消せます。取り消すと、本ツールはそのアカウントの情報にアクセスできなくなります。

6. 変更

内容を変更する場合は、このページを更新します。
